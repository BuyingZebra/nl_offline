# LCD Material Lab 001 — source and scientific provenance

This is an **independent WebGL2 / JavaScript adaptation** made for NOMAD's static Tetris title and laboratory scenes, not a copy or complete port of Retro Display Lab's Vulkan/RetroArch five-pass implementation.

- Original project: **Retro Display Lab**, by JohnnySun, https://github.com/JohnnySun/retro-display-lab

## Elements derived from upstream
1. `physics-data.js` contains the *nominal 20°C and contrast 1* director-drift field (4 × 65 samples), director targets, 65-bin optical-response samples, four optical anchor values, and interpolation corrections from `models/nintendo-dmg-01/generated/ws2-stn-physics-v1.json`. These data were generated by upstream's period-constrained STN director / reflective optics model.
2. The five sRGB optical states in `physics-data.js` are taken from `models/nintendo-dmg-01/data/reconstruction-v1.json`, based on reference color measurements documented there.
3. `model.js` implements a compact CPU per-cell dynamic integration inspired by `models/nintendo-dmg-01/shaders/dmg01-response-v1.slang`. It uses the physical director-drift table and an optional tiny ionic retention state. The full upstream phase-local electrical drive and Simpson-integrated frame exposure are **not** included.
4. `lab.js` independently adapts the area-integrated periodic cell aperture, displaced reflector shadow, joint aperture/shadow overlap, five-state interpolation in linear light, and contrast/brightness/chroma parameters of `models/nintendo-dmg-01/shaders/dmg01-display-v1.slang`, especially the analytical aperture treatment.

## Honest limits
- This first experimental port **does not** implement upstream's five-pass passive-matrix row/column electrical RC crosstalk model, row-load and common-electrode phases, source-frame latch timing, full multi-condition STN physics solver, or original GPU feedback encoding.
- The model currently samples four logical Tetris shades, updates every browser animation frame using elapsed real time, and uses one nominal STN director-drift condition. Browser timing and output display calibration differ from the original RetroArch target.
- `NOMAD experimental colour` is an invented comparative palette, not an original Game Boy measurement. The virtual front-glass highlight, faux illumination, and view angle are **our own artistic experiments**, not validated properties of a particular DMG panel.
- The final result must be tested on physical iPhone Safari for numerical behavior, GPU shader compilation, and pixel visibility before claiming photographic or panel-specific accuracy.
- Real ambient illumination, polarization spectra, device screen colour calibration and true reflected light are not physically reproduced by an emissive phone.

This document and the upstream license are supplied to preserve provenance and make future model comparisons auditable.
