# Newfoundland and Labrador community search index (v0.29)

`nl-places.json` is generated by `tools/build-nl-places.py` from the
[Canadian Geographical Names Database (CGNDB)](https://natural-resources.canada.ca/maps-tools-publications/maps/geographical-names-canada/download-geographical-names-data),
using the official Newfoundland and Labrador CSV ZIP.

- Source: Natural Resources Canada, Canadian Geographical Names Database.
- Licence: [Open Government Licence - Canada](https://open.canada.ca/en/open-government-licence-canada).
- Filter: CGNDB `Generic Category == Populated Place`, plus the documented
  official Natuashish community point (`ACJUH`) classified as a `SITE`.
- Current build: 1,458 searchable features. Includes 235 official records
  classified as vacated or seasonal settlements, which are labelled accordingly.
- Point location: CGNDB georeferenced feature coordinate in WGS84; for some
  incorporated towns this can be a municipality reference point rather than
  downtown or a routable street entrance.
- Historic and seasonal records are surfaced with a distinguishing label;
  the presence of an official place name is not evidence that roads, residents,
  or navigable access still exist.
- Names are preserved from their government records; punctuation and accent
  folding is performed *only for matching*.
- Entries have stable CGNDB IDs to avoid merging distant communities with
  identical names. The `region` field is the provider's free-form `Location`
  attribute, **not** a guaranteed municipal affiliation.

This index improves Newfoundland-wide **map viewpoint search**, not civic
address geocoding, road routing, or road-snapped destination selection.

### Regeneration

Run `python tools/build-nl-places.py` with network access; the original
government CSV is updated regularly. Review the record count, changed
coordinates, duplicates, and examples before deploying. The workflow
`build-nl-places.yml` regenerates the development dataset on its feature
branch and only commits if validation passes.

### Scope limitations

The official gazetteer is much more complete than the former six presets but
is not guaranteed to include every named inhabited community, or an ideal map
camera center for each administrative polygon. Coverage should eventually be
audited against local/Indigenous names and relevant provincial community
records. A separate road network is needed for navigation.
