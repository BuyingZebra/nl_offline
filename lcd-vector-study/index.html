Why two layers? The original Game Boy hardware model cannot exactly reproduce independent behaviour within an electrode. Its electric field and original five passes are preserved here, while fine detail response is a separate approximation. Compare the three views to distinguish the physically calculated behaviour from the reconstruction. RUN must be started manually.




Exact upstream model conditions


Original reference mode: 0.875 pixel aperture fill, 1.00 host-footprint filtering, 0.18 reflector shadow, 0.11/0.13-cell shadow offset, contrast 1.00 and zero simulated aging. Cell-less mode: the aperture/gaps are omitted; a continuous displaced-shading analogue replaces the gap-dependent reflector shadow. Original optical colour and contrast parameters are retained.


Electrical: reconstructed STN drive with original generated director tables, row+column crosstalk 1.00, 20°C, ionic history, captured row latch, 59.7275 Hz frame reference. The feedback buffer is 32-bit float.


Output: 640 × 576 high-resolution artwork and optical buffer. Original electrical state is native 160 × 144 RGBA32F. The new fine-detail response uses two bounded 640 × 576 RGBA8 history buffers; it does not run the expensive physical matrix shader over every output pixel. The comparison is an experiment, not a claim of identical high-resolution Game Boy hardware physics.
