NL Offline v0.11 — Road Test Checklist
=======================================

BEFORE LEAVING
[ ] Open the HTTPS GitHub Pages version while online.
[ ] Confirm the app identifies itself as v0.11.
[ ] Tap Recheck road setup.
[ ] Confirm ROAD READY and a GPS accuracy value.
[ ] Close and reopen the installed Home Screen PWA.

SIMULATION CHECK
[ ] Load Carbonear -> St. John's.
[ ] Confirm 108 km / 1h 11m official trip.
[ ] Tap Follow.
[ ] Move the simulation slider.
[ ] Confirm the map follows the simulated position and remaining km decreases.
[ ] Tap Route to return to the full-route overview.

LIVE ROAD CHECK
[ ] Set From to Current location.
[ ] Choose destination and Show trip.
[ ] Tap Start driving.
[ ] Confirm GPS changes to GPS live.
[ ] Confirm Follow centres on your position.
[ ] Confirm travelled/remaining values update as you move.
[ ] Note whether ETA settles after several kilometres.
[ ] If you intentionally leave the route, note when OFF ROUTE appears.
[ ] Return to route and confirm it recovers without rapid flicker.

OFFLINE CHECK
[ ] After ROAD READY, enable airplane mode or enter a no-service area.
[ ] Reopen NL Offline.
[ ] Confirm town search, Level 1 distance/time and Level 2 map still load.

FERRY CHECK (can be simulated)
[ ] Load Ramea -> Burgeo.
[ ] Confirm total 24 km / 1h 24m.
[ ] Confirm breakdown shows Road 2 + ferry 22 km and Road 4 min + ferry 1h 20m.
[ ] Confirm Level 2 is marked Schematic rather than showing a false road route.

REPORT
Record any route where:
- map path visibly leaves the real road,
- official numbers look wrong,
- GPS jumps forward,
- Follow loses the vehicle,
- labels flicker/overlap,
- app fails after losing service,
- or a ferry trip is represented incorrectly.
